# Freeverse / LAOS Network

> Freeverse is the team behind the LAOS Network, an EVM-compatible public blockchain (Polkadot parachain) for Bridgeless Minting and Evolution of NFTs. Applications mint and dynamically evolve digital assets whose ownership is enforced on Ethereum and Polygon while asset logic and gas live on LAOS. The LAOS Foundation maintains a public GraphQL API for creating collections, minting up to 700 NFTs atomically, evolving assets, broadcasting to marketplaces, and running read queries over an on-chain indexer. Read queries are open; write mutations require an API key.
